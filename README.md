# StockWatch

Personal portfolio management system project to practice, learn and apply software development practices.

Full expected future tech stack :

Backend : Java, Spring Boot, Maven
Frontend : React, Javascript/Typescript, CSS/Tailwind
Database : PostgreSQL, Spring Data JPA, Hibernate
Testing : JUNIT5 (unit testing), Mockito (dependencies), Spring Boot Test (Integration testing), Postman (API Testing)
DevOps/Deployment : Docker / Docker Compose, Github Actions
Version control : Git
