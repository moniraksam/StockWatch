# StockWatch

StockWatch is a personal investment portfolio management application designed to track stock holdings, manage buy/sell transactions, and monitor portfolio performance.

## Planned Features

- Portfolio management and transaction history.
- Financial performance tracking and profit/loss calculations.
- RESTful APIs and PostgreSQL persistence.
- Secure authentication and authorization with Spring Security.
- Protection against common vulnerabilities (OWASP Top 10), including broken access control, injection, and authentication flaws.
- Security testing, input validation, and API rate limiting.
- Responsive React dashboard.
